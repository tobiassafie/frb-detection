# hls_projects — synthesis handoff (Stage 2 CNN + Stage 3 LSTM/GRU)

Generated by `scripts/hls_export.py` (hls4ml 1.3.0, Vitis backend, part `xcvu9p-flga2104-2L-e`,
5 ns clock). **Nothing here has been synthesised yet**: the machine that generated it has no
Vitis HLS and no C++ compiler. Index of every project, with float accuracy and the local
fixed-point *emulation* accuracy: `results/hls_projects_index.csv` (+ `est_*` analytic
estimates from `scripts/hls_estimates.py`).

## Run on the EC2 box (Vitis 2025.1, same setup as `fpga_handoff/`)

```bash
cd hls_projects
bash run_all_synthesis.sh 4          # 4 projects in parallel; each csynth-only, killed at 20 min -> "timeout"
# -> synth_results.csv  (status ok/timeout/error_N, synth seconds, latency cycles/us, II,
#                        est. clock -> Fmax, DSP/LUT/FF/BRAM/URAM, last ERROR lines if it failed)
python3 check_accuracy.py <project> [n]   # bit-accurate C-sim accuracy on the v7 TEST split
                                          # (needs g++, TF 2.x, hls4ml 1.3; appends csim_accuracy.csv)
```

Copy `synth_results.csv` and `csim_accuracy.csv` back to `results/`; `scripts/make_summary.py`
then uses real csynth numbers instead of estimates.

Each project's `run_vitis_synthesis.sh` writes `build_opt.tcl` options identical to
`hls4ml VitisBackend.build(reset=True, csim=False, synth=True)` and runs
`vitis-run --tcl build_prj.tcl --mode hls` (the same command hls4ml uses), wrapped in `timeout 1200`.

## Project naming

`<run_id>__<Res|Lat>_rf<R>_<precision>`; `run_id` is the row in `results/sweep_results.csv`
(model weights in `source_model.*` inside each project).

| family | run_id | what it is |
|---|---|---|
| CNN, synthesis track (B) | `s1mB_t0041_rfi` | float model, 128×128 input, Conv(4,8,16,16,16)+ReLU+AvgPool, GAP, Dense16, 6,433 params; PTQ at ap_fixed<8,3>…<16,6>, RF 1/4/16/64, + Latency RF1 |
| CNN QAT 8-bit | `qat_s1mB_t0041_rfi_8b` | same architecture, QKeras 8-bit QAT (input stays ap_fixed<16,6>) |
| CNN QAT 6-bit | `qat_s1mB_t0041_rfi_6b` | same, 6-bit |
| LSTM | `s3r_lstm_u16_T64_F8_lr0.003_do0.2_d0` | 1 LSTM layer, 16 units, 64 timesteps × 8 freq channels, 1,617 params; io_parallel, static, Resource, RF 1/4/16, ap_fixed<12..16,6> |
| GRU (fallback) | `s3r_gru_u16_T64_F8_lr0.003_do0.0_d16` | 1 GRU layer 16 units + Dense16, 1,537 params |
| tiny LSTM | `s3_lstm_u4_T32_F16` | 4 units, 32×16 input, 341 params — most likely to synthesise |

Inputs: the model input is the 256×256 (time × freq) patch block-averaged to the model's
resolution, in units of per-channel noise σ, represented as ap_fixed<16,6> (that binning and the
per-channel normalisation happen upstream of the model).
